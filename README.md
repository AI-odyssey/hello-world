# MZ 성경 📖🔥

성경 본문을 요즘 유행하는 MZ(잘파)식 표현으로 의역해서 보여주는 모바일 앱입니다.
Expo(React Native) 기반이라 iOS/Android/웹에서 동시에 확인할 수 있습니다.

지금은 **창세기 1장** 한 챕터만 들어있는 프로토타입 단계입니다. 구조를 검증한 뒤
다른 책/장을 순차적으로 추가할 계획입니다.

## 실행 방법

```bash
npm install
npm start        # Expo 개발 서버 실행 → QR 코드를 Expo Go 앱으로 스캔
npm run web      # 브라우저에서 바로 확인
```

## 프로젝트 구조

```
src/
  data/
    genesis1.ts     # 창세기 1장 데이터 (원문 쉬운말 + MZ 버전)
  components/
    ModeToggle.tsx   # "쉬운말 / MZ 버전" 전환 토글
    VerseCard.tsx    # 절 하나를 보여주는 카드
  screens/
    ChapterScreen.tsx  # 한 장(챕터)을 보여주는 화면
App.tsx             # 진입점
```

### 새로운 장(챕터)을 추가하려면

1. `src/data/` 아래에 `genesis1.ts`와 같은 형태로 새 파일을 만들고
   `Chapter` 타입에 맞춰 `verses` 배열을 채웁니다.
2. 여러 장을 다루게 되면 책 목록 → 장 목록 → 본문 순서의 내비게이션이
   필요합니다 (다음 단계에서 추가 예정).

## 번역 원칙

- 특정 저작권 번역본(개역개정 등)을 그대로 베끼지 않고, 원문의 의미를 기준으로
  자체적으로 쉬운말 풀이를 작성한 뒤 그걸 MZ 표현으로 의역합니다.
- 내용의 진지함은 해치지 않으면서, 표현만 요즘 말투(오운완, 갓생, 인정, 개꿀 등)로
  바꾸는 것이 목표입니다.
