# 모니터링 대시보드

프로젝트별로 목적과 키워드를 할당하고, 모니터링 대상 사이트(공통 사이트 + 프로젝트 전용 사이트)를
관리하는 통합 대시보드입니다.

## 기능

- **프로젝트 관리**: 프로젝트 이름, 목적, 키워드를 등록/수정
- **공통 사이트 관리**: 모든 프로젝트가 공유하는 모니터링 대상 사이트 등록/수정/삭제
- **프로젝트 전용 사이트 관리**: 프로젝트별로 추가 탐색 대상 사이트 등록/수정/삭제

## 시작하기

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- 데이터 저장: `data/db.json` (로컬 파일 기반, 실행 시 자동 생성됨)

데이터 접근 로직은 `src/lib/db.ts` 한 곳에 모여 있어, 추후 Supabase 등 외부 데이터베이스로
교체하기 쉽게 구성했습니다.
